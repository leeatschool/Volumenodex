# Volumenodex Sound Samples Directory

Place your custom MP3 audio files in this directory (`Volumenodex/assets/sounds/`).

### Typewriter Keystroke Samples
- `manual_click1.mp3` — Primary mechanical typewriter key strike
- `manual_click2.mp3` — Subtle variation keystroke
- `manual_click3.mp3` — Subtle variation keystroke
- `bell.mp3` — Classic carriage return bell chime (plays on Enter / margin)
- `electric_click.mp3` — Crisp electric typewriter sound
- `soft_mechanical.mp3` — Muted soft mechanical switch click

### Ambient Soundscapes (Looping)
- `rain.mp3` — Gentle rain on windowpane
- `library.mp3` — Quiet library atmosphere
- `fireplace.mp3` — Warm crackling fireside
- `coffee_shop.mp3` — Cozy cafe murmurs and coffee cups
- `cabin.mp3` — Cabin in the woods / gentle wind
- `camping.mp3` — Camping under the stars / crickets & night breeze
- `brown_noise.mp3` — Deep brown noise for intense focus
